Connect your Anthropic API key

ClipForge calls the Claude API directly from your browser, so it needs your own API key. Get one at platform.claude.com.

Your key is stored only in this browser (localStorage) and sent only to api.anthropic.com. Anyone with access to this browser profile can read it — don't use a shared computer, and use a key you can revoke.
